# 📄 Anti-Gravity 에이전트 시스템 설계 및 명령 조치 이력서

## 💡 프로젝트 가치 요약
- 본 문서는 단순 모니터링 시스템을 넘어 사용자가 단일 파일 실행 시 [검출 -> 조치 -> 보고]를 완전 자동화하는 파이프라인의 설계 사상을 기록합니다.

## 👥 에이전트간 역할 분담 이력
1. **가이드 분석 에이전트:** KISA 상세 가이드를 분석하여 정형 데이터(`KisaCriteria.json`)로 구조화 완료.
2. **플레이북 설계 에이전트:** 멱등성 및 자동 백업/롤백(Try-Catch)을 내장한 `Detector` 및 `Remediation` 파워쉘 핵심 모듈 개발 완료.
3. **감사 및 보고서 에이전트:** 런타임 결과 수집 모듈(`Reporter`) 설계 및 본 시스템 아키텍처 이력 마크다운 문서 자동 생성 완료.
4. **통합 패키징 에이전트:** 관리자 권한 예외 처리가 적용된 메인 오케스트레이터 스크립트(`Run-Patcher.ps1`) 검증 및 최종 빌드 완료.

## 🔧 프로그램 실행 메커니즘 흐름
- 사용자 액션: `Click-Me-To-Patch.bat`을 통한 실행 정책 우회 및 관리자 권한 구동
- 1단계 (검출): 현재 인프라 상태 측정 후 기준값과 대조 판정 (`Core/Detector.psm1`)
- 2단계 (조치): 파일/레지스트리 자동 백업 진행 후 멱등성 기반 강제 치환 패치 및 디바이스 리로드, 오류 시 자동 원상복구 (`Core/Remediation.psm1`)
- 3단계 (평가 및 보고): 포스트 감사 수행 후 `Reports/Security_Patch_Report.md` 파일에 조치 이력 실시간 적재 (`Core/Reporter.psm1`)
