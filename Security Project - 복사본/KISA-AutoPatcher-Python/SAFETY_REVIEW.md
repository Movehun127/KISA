## 실행·복원 범위

자동 쓰기는 백업과 읽기 검증을 구현한 Registry/Secedit 유형만 지원합니다. 나머지 항목은 수동 검토 또는 진단 전용입니다. 자동화 범위를 과장하지 않기 위한 의도적인 제한입니다. 기존 dist EXE는 다시 빌드하지 않았으며 이 수정이 포함되지 않습니다.
변경 전 JSON 백업을 디스크에 기록한 뒤 적용합니다. 실패하면 해당 백업의 원래 값과 자료형을 복원하고 확인합니다. 원래 없던 레지스트리 값은 삭제합니다(새로 만들어진 빈 키는 남을 수 있음). Secedit도 변경 대상 키만 복원합니다.
자동 조치 대상에서 도메인 가입·도메인 컨트롤러 및 환경 조회 실패 장비를 제외합니다. GPO/MDM/보안 에이전트의 유효 정책과 재적용 여부는 별도로 확인해야 합니다.
운영 영향 항목은 GUI에서 항목별 확인을 받아야 실행됩니다. 이는 기능 영향 검토의 대체 수단이 아닙니다. 서비스·NIC·방화벽·계정 일괄 자동 변경은 지원하지 않습니다.

수동 복원: 프로그램 폴더에서 관리자 권한으로 아래 명령을 실행합니다. 이 프로그램이 생성한 해당 PC의 백업만 선택하세요.

```powershell
python -c "from core.remediator import restore_backup; restore_backup(r'backups\W-10_실제파일명.json')"
```

## 검증 및 남은 범위

Linux에서 Windows 호출을 모의한 회귀 테스트와 Python 구문 검사를 수행했습니다. 실제 레지스트리, Secedit, UAC, 한국어/영어 Windows GUI, COM 및 EXE는 실행 검증하지 못했습니다.
배포 전 Windows 10/11 및 Server 2016/2019/2022 시험 VM에서 스냅샷을 만들고: 진단 → 단일 항목 적용 → 값 재조회 → 업무 기능 테스트 → 백업 복원을 수행하세요. 관리자/비관리자·도메인/독립형·한/영 환경, GPO 재적용, 권한 거부·디스크 부족·타임아웃·중지 요청을 포함합니다.
W-09 구성값 확인은 실제 암호의 조합/길이 감사가 아닙니다. W-47은 현재 실행 사용자만 검사합니다. W-28/36은 구성값 점검으로 실제 RDP 유효 설정과 서비스 비사용 예외는 수동 검토가 필요합니다. 이 항목들의 자동 점검 통과를 전체 준수로 해석하지 마세요.
